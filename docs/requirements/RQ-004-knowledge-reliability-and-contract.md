# RQ-004：知识检索契约、任务可靠性与恢复

## 状态

规划需求，尚未选为实施中的唯一活动需求。

## 范围

实现 Agent Runtime 检索契约、`PROCESS`/删除索引任务领取与租约、延迟重试、人工同步发布的补偿与索引对账、备份恢复和 Milvus 重建。首期不实现定时发布、自动到期下线或发布任务。

## 验收标准

1. 检索接口区分有效证据、无证据和依赖不可用，并具有可追踪的契约测试。
2. `PROCESS`/删除索引任务的重复投递、租约超时和进程重启不会破坏 revision 状态或产生冲突 Entity。
3. 人工发布、回滚与下线使用 release 版本 CAS；Milvus 预启用、CAS 失败补偿、旧 Entity 关闭失败和人工索引对账都有集成测试。
4. Qwen embedding profile 的模型版本、4096 维输出和归一化方式可在启动时校验；profile 变更触发新 collection 重建。
5. MySQL 与文件卷可按同一备份批次恢复，Milvus 可重建，恢复演练覆盖组织隔离和活动版本复核。

## 依赖

- `g2rain-common` 的可信主体、错误和返回契约。
- Agent Runtime 的服务身份与契约测试环境。
- `g2rain-deploy` 的知识服务持久化、健康检查、备份与恢复编排。
