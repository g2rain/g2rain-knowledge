# 完成定义

一个知识域变更完成前应满足：

- 需求、接口、数据迁移、配置、运维和安全影响已同步记录。
- 所有状态迁移具备授权、审计和失败回收路径。
- 已发布检索始终经过 `organ_id`、`searchable`、可选标签和 MySQL 活动 revision 复核。
- Maven 模块依赖保持 `startup → biz → api`，生成 CRUD 与领域用例边界清晰。
- 新增外部依赖已定义超时、重试、限流、错误映射与敏感数据处理。
- 自动化测试覆盖成功、拒绝、重试、回滚及跨租户路径，并记录实际执行结果。
- 对外契约或检索质量变化已评估 Agent Runtime 与运营流程的兼容性。
- 新增管理命令已经验证状态前置条件、能力点、乐观锁/幂等与审计；未定义的 IAM 角色映射不以临时绕过方式上线。
