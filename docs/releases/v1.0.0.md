# v1.0.0 · G2rain（谷雨） 知识库服务

G2rain（谷雨）开源智能体平台的知识服务首个稳定版，面向知识运营、客服问答与 Agent 知识接入。

## 本次发布

- 文件与 FAQ 知识、分类与标签、主题与版本管理。
- 草稿提交审核、审核后处理、版本发布与回滚，以及原文受控下载。
- Docling、Embedding、Milvus 与可选 Rerank 的检索处理链路。
- `POST /knowledge/retrieve` 返回经组织与活动版本校验的证据；`POST /knowledge/answer` 基于证据与服务端模板组织回答。
- MySQL 作为元数据与发布状态权威，Milvus 作为可重建检索投影；以 Gateway 准入和 Starter 租户隔离执行访问边界。

## 配套与使用

- 配套前端：[g2rain-knowledge-app v1.0.0](https://github.com/g2rain/g2rain-knowledge-app/releases/tag/v1.0.0)。
- 构建条件：JDK 25、Maven 3.9+；运行需配置 MySQL、知识文件持久化目录、Docling、Milvus 与模型服务。
- [配置说明](https://github.com/g2rain/g2rain-knowledge/blob/v1.0.0/docs/operations/configuration.md) · [接口契约](https://github.com/g2rain/g2rain-knowledge/blob/v1.0.0/docs/api/integration-contracts.md)。
- 构建版本为 `1.0.0`。镜像发布目标为 `ghcr.io/g2rain/g2rain-knowledge:1.0.0`，实际可用性以 GHCR 发布结果为准；不宣称发布 Maven 制品或独立安装包。

## 已知限制

- 多实例任务的持久输入快照、租约代次与运行中协作取消仍有延期项；不承诺所有并发与灾备场景已经覆盖。
- 下线 / 对账等完整发布恢复操作仍见开发计划；发布、回滚应按当前接口与运维方案执行。
- 任务、切片、反馈等通用保存接口仍有字段白名单收紧项；通过 Gateway 按可信运营身份控制准入。服务内不另行提供一套细粒度岗位门禁。
- 具体实现边界见[架构差异](https://github.com/g2rain/g2rain-knowledge/blob/v1.0.0/docs/architecture/deviations.md)，部署与备份能力按环境配置和验证。
