# v1.0.1 · G2rain（谷雨）开源智能体平台知识库服务

v1.0.1 是知识库服务的维护版本，更新平台定位与 Maven 项目元数据，完善 GHCR 容器镜像发布流程，并更新 Apache License 2.0 版权年份及许可证链接。

## 本次变更

- Maven 项目版本更新为 `1.0.1`。
- 项目描述明确定位为 G2rain（谷雨）开源智能体平台的知识库服务，概述知识接入、版本管理、审核发布、检索引用与受控问答能力。
- README 与项目登记文档统一采用 G2rain（谷雨）开源智能体平台定位。
- 新增 GitHub Actions 工作流：推送符合规则的稳定版 tag 后，构建并测试工程，再发布 `ghcr.io/g2rain/g2rain-knowledge:<version>` 与对应提交 SHA 标签。
- 镜像工作流不自动创建 GitHub Release，也不自动部署服务。
- Apache License 2.0 版权年份更新为 `2025-2026`，POM 许可证链接改为 Apache 官方 HTTPS 地址。

## 镜像发布

推送版本 tag（例如 `v1.0.1`）触发镜像构建。tag 必须指向 main 历史中的提交，并且仓库内需包含对应版本的发布说明。镜像使用 GitHub Actions 提供的 `GITHUB_TOKEN` 发布到 GHCR。

## 验证状态

本次版本的完整构建、测试及镜像推送结果应以对应 GitHub Actions 运行记录为准。未在此发布说明中声明尚未完成的 CI 验证或服务器验证结果。

## 配套版本

配套前端版本及兼容性请以 `g2rain-knowledge-app` 的发布说明为准。
